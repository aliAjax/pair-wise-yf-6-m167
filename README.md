# 家庭维修 · 上门排期台

端口规划：`5114`

```bash
npm install
npm run dev
```

在第一版（记录维修问题、状态筛选、预计费用、照片链接、localStorage 存档）基础上，扩展为上门排期台：

- **批量排期**：待处理事项按日期与两小时时段（08:00–20:00，共 6 档）预约师傅，一次可提交多行。
- **整批退回**：任一行字段不全、事项状态不对，或同一位师傅在交叠时段已有一单（含批次内部互撞），整批驳回，事项与排期保持原样。
- **到场流转**：师傅到场后预约转「已到场」，事项同步进入「处理中」。
- **取消预约**：未到场预约可取消，必须填写缘由，取消后该时段立即让出，取消记录保留可查。
- **处理中改期**：处理中事项可以改期，但日期不得晚于已排待到场事项的最晚日期，且仍受同师傅交叠时段约束。
- **联动与存档**：状态筛选与预计费用合计随数据联动（合计按当前筛选口径统计），全部数据存入 localStorage，重开浏览器可继续。

模块划分（三个业务模块各自独立）：

| 模块 | 文件 | 职责 |
| --- | --- | --- |
| 规则 | `src/rules.js` | 纯函数：时段定义、交叠撞车、整批校验、改期上限、筛选与费用合计 |
| 流转 | `src/flow.js` | 状态机与 localStorage 存档：新增、排期、到场、取消、改期、完成、删除 |
| 呈现 | `src/main.js` | DOM 渲染与交互：批量排期表、事项卡片、近期排期、取消缘由、改期表单 |
