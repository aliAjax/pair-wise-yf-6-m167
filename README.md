# 家庭维修 · 上门排期台

端口规划：`5114`

```bash
npm install
npm run dev
```

## 功能

- 记录家庭维修事项（位置、问题、优先级、预计费用、照片链接、备注）
- 待办事项在「批量排期台」按日期与两小时时段（08:00–18:00，共 5 段）预约师傅
- 同一位师傅在交叠时段只能承接一单；与已预约/处理中订单冲突即判撞车
- **整批提交为原子操作**：任一条字段不全或时段撞车，整批退回，事项与已填草稿保持原样
- 师傅到场后事项转为「处理中」（仍占用该时段）
- 取消未到场预约必须写明缘由，提交后事项回到待处理并让出时段，缘由保留在卡片上
- 处理中事项改期时，日期不得晚于尚未到场的已排事项，也不能撞上师傅的其他时段
- 完成维修后释放师傅时段
- 按状态筛选（全部/待处理/已预约/处理中/已完成），统计未完成、已预约、处理中数量与预计费用合计
- 筛选、事项与排期草稿均通过 localStorage 存档，重开浏览器可继续；自动兼容旧版数据

## 代码结构（三个业务模块）

| 模块 | 文件 | 职责 |
| --- | --- | --- |
| 规则 | `src/rules.js` | 两小时时段定义、时段交叠判定、同师傅撞车校验、批量校验、改期与取消缘由校验 |
| 流转 | `src/flow.js` | 状态机（待处理→已预约→处理中→已完成）、批量预约、到场、取消、改期、localStorage 存档与费用合计 |
| 呈现 | `src/view.js` | DOM 渲染与事件绑定，业务判定全部委托给规则/流转模块 |

`src/main.js` 仅负责加载存档并启动页面。
